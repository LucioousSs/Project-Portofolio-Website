# Portfolio Website

Versi awal website portfolio pribadi. Dibangun dengan HTML, CSS, dan JavaScript, tanpa framework.

## Bagian

- Home
- About
- Services
- Education
- Contact

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Remix Icon (ikon, lewat CDN)

## Menjalankan

Buka `index.html` di browser.

## Isi Repo

| File | Keterangan |
| --- | --- |
| `index.html` | Struktur halaman |
| `style.css` | Styling |
| `script.js` | Interaksi |
| `CV.I PUTU ADHIATMAN.pdf` | CV |
